# WATERMARK TOOL

내 컴퓨터에서만 돌아가는 **이미지 워터마크 자동 삽입 프로그램**입니다.
사진을 올리면 **크기는 하나도 바뀌지 않은 채로** 워터마크만 얹어서 내려받을 수 있습니다.

- 인터넷에 사진이 올라가지 않습니다. 전부 내 컴퓨터 안에서 처리됩니다.
- 여러 장을 한 번에 처리하고 ZIP 한 개로 받을 수 있습니다.
- 한 번 정한 위치·크기·투명도는 저장되어 다음에 켤 때 그대로 나옵니다.

---

## 1. 처음 한 번만 하는 준비 (약 5분)

### 1단계. 파이썬(Python) 설치

이 프로그램은 "파이썬"이라는 무료 프로그램 위에서 돌아갑니다.

1. https://www.python.org/downloads/ 에 들어갑니다.
2. 노란색 **Download Python** 버튼을 눌러 내려받고 실행합니다.
3. **⚠️ 윈도우 사용자 주의:** 설치 첫 화면 아래쪽의
   **`Add python.exe to PATH`** 체크박스를 **반드시 켠 다음** `Install Now` 를 누르세요.
4. 맥(Mac)은 그냥 안내대로 계속 누르면 됩니다.

### 2단계. 이 폴더를 열고 "명령 프롬프트/터미널" 띄우기

**윈도우**
1. 이 폴더(`app.py` 가 들어 있는 폴더)를 파일 탐색기로 엽니다.
2. 주소창(폴더 경로가 적힌 칸)을 클릭하고 `cmd` 라고 친 뒤 Enter.
3. 검은 창이 하나 뜹니다. 여기에 글자를 칩니다.

**맥**
1. 이 폴더를 Finder 로 엽니다.
2. 폴더 안 빈 곳에서 마우스 오른쪽 클릭 → **폴더에서 새로운 터미널 열기**.

### 3단계. 필요한 부품 설치 (한 번만)

열린 검은 창에 아래 한 줄을 그대로 붙여 넣고 Enter 를 누르세요.

**윈도우**
```
pip install -r requirements.txt
```

**맥**
```
pip3 install -r requirements.txt
```

글자가 주르륵 올라가다가 멈추면 완료입니다. (1~3분)

## 2. 프로그램 실행하기 (매번 이렇게)

같은 검은 창에 아래 한 줄을 붙여 넣고 Enter.

**윈도우**
```
streamlit run app.py
```

**맥**
```
python3 -m streamlit run app.py
```

잠시 뒤 **인터넷 브라우저가 저절로 열리면서 프로그램이 나타납니다.**
(안 열리면 브라우저 주소창에 `http://localhost:8501` 을 직접 입력하세요.)

> 처음 실행하면 이메일을 입력하라는 문구가 나올 수 있습니다.
> 그냥 **Enter** 만 누르면 넘어갑니다.

**끝낼 때:** 브라우저 창을 닫고, 검은 창에서 `Ctrl` + `C` 를 누릅니다.

## 3. 사용법

화면은 위에서 아래로 5단계입니다. 순서대로 내려오면 됩니다.

### 1. 워터마크 PNG 선택
- 내 로고 PNG 파일(**배경이 투명한 PNG**)을 올립니다.
- 매번 올리기 귀찮다면, 이 폴더의 **`watermark.png` 파일을 내 로고 파일로 바꿔치기** 해 두세요.
  그러면 켤 때마다 자동으로 그 파일이 쓰입니다.
  (지금 들어 있는 `watermark.png` 는 "YOUR LOGO" 라고 적힌 예시 파일입니다.)

### 2. 이미지 업로드
- JPG · JPEG · PNG · WEBP 를 지원합니다.
- 여러 장을 한꺼번에 끌어다 놓을 수 있습니다.

### 3. 워터마크 설정

| 항목 | 설명 |
| --- | --- |
| 워터마크 크기 | `이미지 너비 대비 %` 또는 `픽셀(px)` 중 선택. 기본 16% |
| 워터마크 투명도 | 100 = 원본 그대로, 낮출수록 옅어짐 |
| 워터마크 위치 | 왼쪽 위 / 오른쪽 위 / 왼쪽 아래 / 오른쪽 아래 / 중앙 / 사용자 지정 |
| 여백 | 가장자리에서 얼마나 띄울지. `%` 또는 `px` |
| X · Y | 위치를 "사용자 지정"으로 골랐을 때만 나옵니다. 워터마크 **왼쪽 위 모서리** 좌표 |

**크기를 %로 하면 좋은 점:** 큰 사진이든 작은 사진이든 워터마크가 항상 같은 비율로 들어갑니다.

### 4. 미리보기
- 결과가 바로 보입니다. 여러 장이면 위 목록에서 골라서 확인할 수 있습니다.
- 아래에 `원본 1600 × 1000 px → 결과 1600 × 1000 px` 처럼 크기가 표시됩니다. **항상 같아야 정상입니다.**

### 5. 워터마크 적용 → 다운로드
- **워터마크 적용** 버튼을 누릅니다.
- 한 장이면 → 그 파일 하나만 내려받는 버튼이 나옵니다.
- 여러 장이면 → **전체 ZIP 다운로드** 버튼이 나옵니다. (한 장씩 따로 받기도 가능)
- 파일 이름은 `원본파일명_watermarked.확장자` 로 저장됩니다.
  예) `여행사진.jpg` → `여행사진_watermarked.jpg`

## 4. 프로젝트 구조

```
watermark-tool/
├── app.py             프로그램 본체 (실행하는 파일)
├── requirements.txt   필요한 부품 목록 (설치할 때 사용)
├── config.json        내가 정한 설정이 저장되는 곳 (자동 생성/수정)
├── watermark.png      기본 워터마크 이미지 (내 로고로 바꿔 쓰세요)
└── README.md          이 설명서
```

### config.json 에 저장되는 값

설정을 바꾸면 **자동으로** 저장되고, 다음에 켤 때 그대로 불러옵니다.
직접 손댈 필요는 없지만, 내용은 이렇습니다.

| 항목 | 뜻 | 기본값 |
| --- | --- | --- |
| `size_mode` | 크기 기준 `percent` / `pixel` | `percent` |
| `size_percent` | 이미지 너비 대비 워터마크 너비 % | `16.0` |
| `size_px` | 워터마크 너비(px) | `300` |
| `opacity` | 투명도 0~100 | `100` |
| `position` | `top_left` `top_right` `bottom_left` `bottom_right` `center` `custom` | `bottom_right` |
| `margin_mode` | 여백 기준 `percent` / `pixel` | `percent` |
| `margin_x_percent` / `margin_y_percent` | 좌우 / 위아래 여백 % | `2.5` / `2.0` |
| `margin_x_px` / `margin_y_px` | 좌우 / 위아래 여백 px | `24` / `24` |
| `custom_unit` | 사용자 지정 X/Y 단위 `percent` / `pixel` | `percent` |
| `custom_x_percent` / `custom_y_percent` | 사용자 지정 X / Y (%) | `78.0` / `88.0` |
| `custom_x_px` / `custom_y_px` | 사용자 지정 X / Y (px) | `0` / `0` |

> 기본값은 1920 × 1080 사진 기준으로 워터마크 너비 약 307px,
> 오른쪽 여백 48px, 아래 여백 22px 입니다.

## 5. 이미지가 상하지 않도록 지키는 규칙

| 규칙 | 어떻게 지키는지 |
| --- | --- |
| 크기 그대로 | 원본과 똑같은 크기의 빈 레이어에 워터마크만 얹어 합성합니다. 크롭·리사이즈 코드가 아예 없습니다. |
| 사진 회전 | 스마트폰 사진의 EXIF 회전 정보를 실제 픽셀에 반영한 뒤, 회전 태그를 정리해 어디서 열어도 똑바로 보입니다. |
| PNG 투명도 | 원본이 투명 PNG면 결과도 투명 PNG(RGBA)로 저장합니다. |
| JPG 품질 | `quality=95` 로 저장하고, 원본의 색상 샘플링 방식을 그대로 유지합니다. |
| 색상 프로파일 | 원본에 ICC 프로파일이 있으면 결과에도 그대로 붙입니다. |
| 촬영 정보 | JPG·WEBP 는 EXIF(촬영 날짜·카메라 정보 등)를 유지합니다. |

## 6. 잘 안 될 때

| 증상 | 해결 |
| --- | --- |
| `pip` 또는 `python` 을 찾을 수 없다고 나옴 | 파이썬 설치 때 **Add python.exe to PATH** 를 안 켠 경우입니다. 파이썬을 지우고 그 항목을 켠 채 다시 설치하세요. |
| `streamlit` 을 찾을 수 없다고 나옴 | 3단계 설치 명령(`pip install -r requirements.txt`)을 다시 실행하세요. |
| 브라우저가 안 열림 | 주소창에 `http://localhost:8501` 을 직접 입력하세요. |
| 워터마크가 안 보임 | 투명도가 0에 가깝거나 크기가 너무 작지 않은지 확인하세요. 배경이 흰 사진에 흰 로고면 잘 안 보입니다. |
| 워터마크가 잘려서 나옴 | 위치를 "사용자 지정"으로 두고 X/Y 가 너무 클 때 생깁니다. 값을 줄이거나 위치를 다시 고르세요. |
| 설정이 저장되지 않음 | 폴더가 읽기 전용일 수 있습니다. 바탕화면 등 쓰기 가능한 곳으로 폴더를 옮기세요. |
| 사진이 너무 커서 느림 | 정상입니다. 4천만 화소급 사진 여러 장은 시간이 걸립니다. 진행 막대가 끝날 때까지 기다리세요. |

## 7. 참고

- 처리는 전부 로컬(내 컴퓨터)에서 이뤄지며, 원본 파일은 수정되지 않습니다. 결과는 항상 새 파일로 받습니다.
- 지원 형식: JPG / JPEG / PNG / WEBP · 파일당 최대 200MB
- 사용 라이브러리: [Streamlit](https://streamlit.io) (화면), [Pillow](https://python-pillow.org) (이미지 처리)
