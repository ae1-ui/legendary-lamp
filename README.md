# WATERMARK TOOL

내 컴퓨터에서만 돌아가는 **사진 일괄 편집 + 워터마크 프로그램**입니다.
사진을 여러 장 올리면 **크기를 1080 × 1440 으로 맞추고 → 톤·색감을 보정하고 → 워터마크를 얹어서**
ZIP 한 개로 내려받을 수 있습니다.

- 인터넷에 사진이 올라가지 않습니다. 전부 내 컴퓨터 안에서 처리됩니다.
- 원본 파일은 절대 바뀌지 않습니다. 결과는 항상 새 파일로 저장됩니다.
- 한 번 정한 설정은 저장되어 다음에 켤 때 그대로 나옵니다.

**워터마크는 언제나 맨 마지막에 합성됩니다.** 그래서 흑백으로 만들든, 어둡게 만들든
워터마크만은 원래 색과 밝기 그대로 남습니다.

## 1. 처음 한 번만 하는 준비 (약 5분)

### 1단계. 파이썬(Python) 설치

이 프로그램은 "파이썬"이라는 무료 프로그램 위에서 돌아갑니다.

1. https://www.python.org/downloads/ 에 들어갑니다.
2. 노란색 **Download Python** 버튼을 눌러 내려받고 실행합니다.
3. **⚠️ 윈도우 사용자 주의:** 설치 첫 화면 아래쪽의
   **`Add python.exe to PATH`** 체크박스를 **반드시 켠 다음** `Install Now` 를 누르세요.
4. 맥(Mac)은 그냥 안내대로 계속 누르면 됩니다.

### 2단계. 이 폴더를 열고 "명령 프롬프트/터미널" 띄우기

**윈도우**
1. 이 폴더(`app.py` 가 들어 있는 폴더)를 파일 탐색기로 엽니다.
2. 주소창(폴더 경로가 적힌 칸)을 클릭하고 `cmd` 라고 친 뒤 Enter.
3. 검은 창이 하나 뜹니다. 여기에 글자를 칩니다.

**맥**
1. 이 폴더를 Finder 로 엽니다.
2. 폴더 안 빈 곳에서 마우스 오른쪽 클릭 → **폴더에서 새로운 터미널 열기**.

### 3단계. 필요한 부품 설치 (한 번만)

열린 검은 창에 아래 한 줄을 그대로 붙여 넣고 Enter 를 누르세요.

**윈도우**
```
pip install -r requirements.txt
```

**맥**
```
pip3 install -r requirements.txt
```

글자가 주르륵 올라가다가 멈추면 완료입니다. (1~3분)

## 3. 사용법

화면은 위에서 아래로 7단계입니다. 순서대로 내려오면 됩니다.

### 1. 이미지 업로드
- JPG · JPEG · PNG · WEBP 를 지원합니다.
- 여러 장을 한꺼번에 끌어다 놓을 수 있습니다.
- 올리면 **파일 이름 · 원본 크기 · 비율** 목록이 표로 나옵니다.

### 2. 출력 사이즈

| 출력 크기 | 설명 |
| --- | --- |
| **1080 × 1440 px (3:4)** | 기본값. 어떤 사진을 넣어도 결과는 정확히 이 크기 |
| 직접 입력 | 원하는 가로·세로를 픽셀로 지정 |
| 원본 크기 그대로 | 크기를 바꾸지 않고 보정과 워터마크만 적용 |

**맞추는 방식** (크기를 고정했을 때)

| 방식 | 설명 |
| --- | --- |
| **Crop to Fill** (기본값) | 비율을 유지한 채 화면을 꽉 채우고, 넘치는 부분만 잘라냅니다. 사진이 찌그러지지 않습니다. |
| Fit | 사진 전체가 보이도록 맞추고, 남는 영역은 고른 배경색으로 채웁니다. |
| Stretch | 강제로 늘립니다. 비율이 깨지므로 인물·상품 사진에는 권장하지 않습니다. |

**Crop to Fill 을 골랐을 때 크롭 기준점**
중앙(기본) · 상단 · 하단 · 좌측 · 우측 중에서 고를 수 있고,
그 아래 **좌우 위치 / 상하 위치 슬라이더**로 잘리는 자리를 직접 밀어서 맞출 수 있습니다.

- 가로가 남는 사진(파노라마 등) → **좌우 위치** 슬라이더가 움직입니다.
- 세로가 남는 사진 → **상하 위치** 슬라이더가 움직입니다.
- 기준점을 다시 고르면 슬라이더도 그 자리로 돌아갑니다.

**저장 옵션** (접혀 있는 칸)
- 저장 형식: `JPG (quality 95)` 기본값 / `원본 형식 유지`
- 파일 이름 뒤에 붙일 말: `_edited` 기본값

### 3. 톤 보정

전부 **0이 기본값이고, 0이면 원본 픽셀이 하나도 바뀌지 않습니다.**

| 슬라이더 | 범위 | 무엇이 바뀌나 |
| --- | --- | --- |
| 밝기 Brightness | -100 ~ +100 | 중간 밝기를 올리고 내립니다. 밝은 부분이 잘 타지 않습니다. |
| 노출 Exposure | -100 ~ +100 | 카메라 노출처럼 전체 광량을 조절합니다 (최대 ±1.5스톱). |
| 대비 Contrast | -100 ~ +100 | 밝은 곳과 어두운 곳의 차이 |
| 하이라이트 Highlights | -100 ~ +100 | **밝은 영역만** 조절. 하늘이 하얗게 날아갔을 때 내려 주세요. |
| 그림자 Shadows | -100 ~ +100 | **어두운 영역만** 조절. 얼굴이 어두울 때 올려 주세요. |

### 4. 색감 보정

| 슬라이더 | 범위 | 무엇이 바뀌나 |
| --- | --- | --- |
| 채도 Saturation | -100 ~ +100 | -100 이면 완전 흑백, +면 색이 진해집니다. |
| 색온도 Temperature | -100 ~ +100 | 음수 = 차갑게(파랑), 양수 = 따뜻하게(주황) |
| Tint | -100 ~ +100 | 음수 = Green, 양수 = Magenta |

**보정 초기화** 버튼을 누르면 톤·색감 값 8개가 전부 0으로 돌아갑니다.

### 5. 워터마크
- 배경이 투명한 로고 PNG 를 올립니다.
  매번 올리기 번거로우면 이 폴더의 **`watermark.png` 파일을 내 로고 파일로 바꿔치기** 해 두세요.
  그러면 켤 때마다 자동으로 그 파일이 쓰입니다.
- 크기 · 투명도 · 위치 · 여백을 정합니다. 크기와 여백은 **%** 또는 **px** 중에 고를 수 있습니다.
- **중요:** 워터마크 크기와 위치는 **최종 출력 크기(예: 1080 × 1440)** 를 기준으로 계산됩니다.
  그래서 원본이 가로 사진이든 세로 사진이든, 결과에서는 **항상 같은 자리에 같은 크기**로 들어갑니다.

기본값: 오른쪽 아래 / 너비 16% / 투명도 70% / 오른쪽 여백 2.5% · 아래 여백 2%
(1080 × 1440 기준으로 워터마크 폭 173px, 오른쪽 27px, 아래 29px)

### 6. 미리보기
- **Original**(올린 원본)과 **Edited**(최종 결과)를 나란히 비교할 수 있습니다.
- 여러 장이면 위 목록에서 골라서 확인할 수 있습니다.
- 미리보기는 화면에 보여 줄 때만 줄여서 보여 줍니다. 저장되는 파일은 표시된 크기 그대로입니다.

### 7. 전체 이미지 처리 → 다운로드
- **전체 이미지 처리** 버튼을 누르면 지금 설정이 올린 사진 전부에 똑같이 적용됩니다.
- 한 장이면 → 그 파일 하나만 내려받는 버튼이 나옵니다.
- 여러 장이면 → **전체 ZIP 다운로드** 버튼이 나옵니다. (한 장씩 따로 받기도 가능)
- 이름은 `여행사진.jpg` → `여행사진_edited.jpg` 로 붙습니다.

## 4. 처리 순서

프로그램은 항상 아래 순서로 한 장씩 처리합니다. 순서는 바뀌지 않습니다.

```
1. EXIF orientation 보정   스마트폰 사진의 회전 정보를 실제 픽셀에 반영
        ↓
2. 크롭 / 리사이즈         Crop to Fill · Fit · Stretch 중 고른 방식으로 출력 크기에 맞춤
        ↓
3. 톤 보정                 노출 → 밝기 → 대비 → 하이라이트 → 그림자
        ↓
4. 색감 보정               채도 → 색온도 → Tint
        ↓
5. 워터마크 합성           ← 여기서 처음 등장. 위 보정이 워터마크에 닿지 않음
        ↓
6. 파일 저장               JPG quality 95 · 색상 프로파일 유지
```

보정은 8비트가 아니라 **32비트 실수로 계산한 뒤 마지막에 한 번만 8비트로 되돌립니다.**
하이라이트·그림자 마스크도 부드러운 곡선(smoothstep)이라 하늘 같은 그라디언트에 계단(밴딩)이 생기지 않습니다.

## 5. 프로젝트 구조

```
watermark-tool/
├── app.py             프로그램 본체 (실행하는 파일)
├── requirements.txt   필요한 부품 목록 (설치할 때 사용)
├── config.json        내가 정한 설정이 저장되는 곳 (자동 생성/수정)
├── watermark.png      기본 워터마크 이미지 (내 로고로 바꿔 쓰세요)
└── README.md          이 설명서
```

### config.json 에 저장되는 값

설정을 바꾸면 **자동으로** 저장되고, 다음에 켤 때 그대로 불러옵니다.
직접 손댈 필요는 없습니다. 값이 잘못되어 있으면 그 항목만 기본값으로 되돌아가고 프로그램은 계속 돌아갑니다.

| 항목 | 뜻 | 기본값 |
| --- | --- | --- |
| `canvas_mode` | `preset`(1080×1440) · `custom` · `original` | `preset` |
| `canvas_w` / `canvas_h` | 직접 입력했을 때의 출력 크기 | `1080` / `1440` |
| `fit_mode` | `crop` · `fit` · `stretch` | `crop` |
| `crop_anchor` | `center` `top` `bottom` `left` `right` | `center` |
| `crop_x` / `crop_y` | 크롭 위치 0~100 (0=왼쪽·위, 100=오른쪽·아래) | `50` / `50` |
| `bg_color` | Fit 방식에서 남는 영역 색 | `#FFFFFF` |
| `brightness` `exposure` `contrast` `highlights` `shadows` | 톤 보정 -100~+100 | 전부 `0` |
| `saturation` `temperature` `tint` | 색감 보정 -100~+100 | 전부 `0` |
| `size_mode` | 워터마크 크기 기준 `percent` · `pixel` | `percent` |
| `size_percent` / `size_px` | 워터마크 너비 (출력 너비의 % / px) | `16.0` / `300` |
| `opacity` | 워터마크 투명도 0~100 | `70` |
| `position` | `top_left` `top_right` `bottom_left` `bottom_right` `center` `custom` | `bottom_right` |
| `margin_mode` | 여백 기준 `percent` · `pixel` | `percent` |
| `margin_x_percent` / `margin_y_percent` | 좌우 / 위아래 여백 % | `2.5` / `2.0` |
| `margin_x_px` / `margin_y_px` | 좌우 / 위아래 여백 px | `24` / `24` |
| `custom_unit` | 사용자 지정 X/Y 단위 | `percent` |
| `custom_x_percent` / `custom_y_percent` | 사용자 지정 X / Y (%) | `78.0` / `88.0` |
| `custom_x_px` / `custom_y_px` | 사용자 지정 X / Y (px) | `0` / `0` |
| `output_format` | `jpeg` · `keep`(원본 형식 유지) | `jpeg` |
| `name_suffix` | 파일 이름 뒤에 붙는 말 | `_edited` |

## 6. 화질에 대해 지키는 규칙

| 규칙 | 어떻게 지키는지 |
| --- | --- |
| 정확한 출력 크기 | 결과는 언제나 정확히 지정한 픽셀 크기입니다. 화면에도 결과 크기가 표시되고, 전부 맞을 때만 "정확히 1080 × 1440 px 입니다" 문구가 나옵니다. |
| 비율 안 깨짐 | Crop to Fill 과 Fit 은 원본 비율을 그대로 유지합니다. 비율이 깨지는 건 직접 고른 Stretch 뿐입니다. |
| 사진 회전 | EXIF 회전 정보를 실제 픽셀에 반영한 뒤 태그를 정리해, 어디서 열어도 똑바로 보입니다. |
| 워터마크 보호 | 워터마크는 모든 보정이 끝난 뒤에 얹힙니다. 흑백·저노출로 만들어도 워터마크 색은 그대로입니다. |
| 부드러운 보정 | 32비트 실수 연산 + 부드러운 마스크로 계산해 밴딩(계단 현상)이 생기지 않습니다. |
| 리샘플링 품질 | 크기 변환은 LANCZOS(고품질) 방식입니다. |
| JPG 품질 | `quality=95` 로 저장합니다. |
| 색상 프로파일 | 원본에 ICC 프로파일이 있으면 결과에도 그대로 붙입니다. |
| PNG 투명도 | "원본 크기 그대로 + 원본 형식 유지"로 저장하면 투명도가 유지됩니다. JPG 로 저장할 때는 투명한 부분이 배경색으로 채워집니다. |

## 7. 잘 안 될 때

| 증상 | 해결 |
| --- | --- |
| `pip` 또는 `python` 을 찾을 수 없다고 나옴 | 파이썬 설치 때 **Add python.exe to PATH** 를 안 켠 경우입니다. 파이썬을 지우고 그 항목을 켠 채 다시 설치하세요. |
| `streamlit` 또는 `numpy` 를 찾을 수 없다고 나옴 | 3단계 설치 명령(`pip install -r requirements.txt`)을 다시 실행하세요. |
| 브라우저가 안 열림 | 주소창에 `http://localhost:8501` 을 직접 입력하세요. |
| 사진의 중요한 부분이 잘림 | 크롭 기준점을 바꾸거나 **좌우/상하 위치 슬라이더**를 움직여 보세요. 전체를 다 보여주고 싶다면 **Fit** 방식을 고르세요. |
| 워터마크가 안 보임 | 투명도가 0에 가깝거나 크기가 너무 작지 않은지 확인하세요. 흰 배경에 흰 로고면 원래 잘 안 보입니다. |
| 색이 이상해짐 | **보정 초기화** 버튼을 누르면 톤·색감이 전부 0으로 돌아갑니다. |
| 설정이 저장되지 않음 | 폴더가 읽기 전용일 수 있습니다. 바탕화면 등 쓰기 가능한 곳으로 폴더를 옮기세요. |
| 슬라이더 반응이 느림 | 고화소 사진일수록 첫 미리보기가 느립니다. 한 번 계산된 뒤에는 빨라집니다. |

## 8. 참고

- 처리는 전부 로컬(내 컴퓨터)에서 이뤄지며, 원본 파일은 수정되지 않습니다.
- 지원 형식: JPG / JPEG / PNG / WEBP · 파일당 최대 200MB
- 사용 라이브러리: [Streamlit](https://streamlit.io) (화면), [Pillow](https://python-pillow.org) (이미지), [NumPy](https://numpy.org) (보정 연산)
