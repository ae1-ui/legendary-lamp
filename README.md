# WATERMARK TOOL

내 컴퓨터에서만 돌아가는 **사진 일괄 편집 + 워터마크 프로그램**입니다.
사진을 여러 장 올리면 **크기를 1080 × 1440 으로 맞추고 → 톤·색감을 보정하고 → 워터마크를 얹어서**
ZIP 한 개로 내려받을 수 있습니다.

- 인터넷에 사진이 올라가지 않습니다. 전부 내 컴퓨터 안에서 처리됩니다.
- 원본 파일은 절대 바뀌지 않습니다. 결과는 항상 새 파일로 저장됩니다.
- 한 번 정한 설정은 저장되어 다음에 켤 때 그대로 나옵니다.

**워터마크는 언제나 맨 마지막에 합성됩니다.** 그래서 흑백으로 만들든, 어둡게 만들든
워터마크만은 원래 색과 밝기 그대로 남습니다.

화면은 **왼쪽 미리보기 / 오른쪽 편집 설정** 2분할입니다.
오른쪽 설정을 아래로 스크롤해도 왼쪽 미리보기는 화면에 그대로 붙어 있어,
슬라이더를 만지면서 결과를 계속 크게 확인할 수 있습니다.

편집값은 **사진마다 따로 저장**됩니다. 1번 사진을 밝게 해도 2번 사진은 그대로입니다.
크롭 위치는 숫자가 아니라 **미리보기에서 프레임을 마우스로 끌어** 잡습니다.

**맥에서는 설치 후 아이콘 더블클릭만으로 실행됩니다.** 터미널 창은 뜨지 않습니다.

컴퓨터에 따라 아래에서 **하나만** 따라 하시면 됩니다. 한 번만 하면 다시 할 일이 없습니다.

### 🍎 맥(Mac)을 쓰신다면

끝나고 나면 **더블클릭 한 번으로 실행**되고, 터미널 창은 전혀 보이지 않습니다.

#### 1단계. 파이썬(Python) 설치

이 프로그램은 "파이썬"이라는 무료 프로그램 위에서 돌아갑니다.
이미 깔려 있다면 건너뛰셔도 됩니다. (설치 프로그램이 알아서 확인합니다)

1. https://www.python.org/downloads/ 에 들어갑니다.
2. 노란색 **Download Python** 버튼을 눌러 내려받고, 안내대로 계속 누르면 끝입니다.

#### 2단계. 설치 프로그램 실행

프로그램 폴더 안 **`mac`** 폴더를 열면 **`install-mac.command`** 파일이 있습니다.

**터미널에서 실행하는 방법을 권합니다.** 인터넷에서 받은 파일이라 더블클릭하면
최신 macOS 가 무조건 막습니다. (`Apple은 …악성 코드가 없음을 확인할 수 없습니다`)
터미널로 열면 이 검사에 걸리지 않습니다.

1. `응용 프로그램 → 유틸리티 → 터미널` 을 엽니다.
2. **`bash `** 를 칩니다. (bash 뒤에 **띄어쓰기 한 칸**, 아직 Enter 누르지 마세요)
3. `install-mac.command` 파일을 **터미널 창 안으로 마우스로 끌어다 놓습니다.**
4. **Enter**

설치는 1~3분 걸립니다. `설치가 끝났습니다` 가 뜨면 완료입니다.

> **경고창이 떴다면** `휴지통으로 이동` 을 누르지 마시고 `완료` 를 누른 뒤 위 방법으로 하세요.
> 파일에 문제가 있는 게 아니라, 서명 없는 스크립트를 macOS 가 일단 막는 것입니다.
>
> 굳이 더블클릭으로 하고 싶다면 `시스템 설정 → 개인정보 보호 및 보안` 을 열고 맨 아래로 내려
> **`그래도 열기`** 를 누르면 됩니다. (예전의 "오른쪽 클릭 → 열기" 는 최신 macOS 에서 통하지 않습니다)

#### 3단계. 확인

프로그램 폴더에 아래 **두 개가 새로 생깁니다.**

| | 하는 일 |
| --- | --- |
| ▶ **워터마크 툴.app** | 더블클릭 → 프로그램이 열립니다 |
| ■ **워터마크 툴 종료.app** | 더블클릭 → 프로그램이 꺼집니다 |

`워터마크 툴.app` 을 화면 아래 **독(Dock)으로 끌어다 놓으면** 다음부터는 독에서 바로 누를 수 있습니다.

1번 사진에서 Brightness +20, 2번 사진에서 Brightness -5 처럼 서로 다르게 둘 수 있고,
1번 → 2번 → 1번으로 돌아와도 각자 마지막 값이 그대로 남아 있습니다.

## 4. 사용법

### 1. 이미지 업로드 (맨 위)
- JPG · JPEG · PNG · WEBP 를 지원하며, 여러 장을 한꺼번에 끌어다 놓을 수 있습니다.
- 올리면 **파일 이름 · 원본 크기 · 맞춤 방식 · 보정한 항목 수** 목록이 표로 나옵니다.

### 왼쪽. 미리보기

위쪽 버튼으로 세 가지를 볼 수 있습니다. 어느 화면에서도 **이미지가 찌그러지지 않습니다.**

| 보기 | 내용 |
| --- | --- |
| **결과 미리보기** (기본) | 크기 맞춤 · 톤 · 색감 · 워터마크가 모두 반영된 **최종 결과**. 위쪽 **👁 누르고 있으면 보정 전** 버튼(또는 이미지 자체)을 누르고 있으면 보정 전 색감이 보이고, 떼면 바로 보정 후로 돌아옵니다. |
| **크롭 위치 조정** | 원본 전체를 원래 비율로 펼쳐 놓고, 그 위에 **출력 비율 프레임(빨간 사각형)** 을 겹쳐 보여 줍니다. 프레임을 마우스로 끌어 구도를 잡고, 모서리를 끌면 확대/축소됩니다. 바로 아래에 저장될 결과가 함께 보입니다. |
| **원본** | 올린 사진 그대로 (원래 비율) |

- **보정 전 / 후 비교:** 결과 미리보기에서 버튼이나 이미지를 **누르고 있는 동안** 보정 전이 보입니다.
  두 장을 미리 브라우저에 보내 두고 바꾸기만 하므로 누르는 즉시 전환됩니다 (기다림 없음).
  비교 대상은 **같은 구도·같은 워터마크에서 톤·색감만 뺀 상태**라 색 차이만 정확히 눈에 들어옵니다.
  톤·색감 값이 전부 0이면 비교할 것이 없으므로 버튼이 흐리게 표시됩니다.
- 오른쪽 설정을 내려도 미리보기는 화면에 붙어 있습니다.
- 원본 파일은 절대 바뀌지 않습니다.

### 오른쪽 1. 편집할 이미지
고른 사진이 미리보기에 뜨고, 아래 2~5번 설정이 **그 사진 것으로** 바뀝니다.

### 오른쪽 2. 출력 방식

| 출력 크기 (사진별) | 설명 |
| --- | --- |
| **1080 × 1440 px (3:4)** | 기본값 |
| **1080 × 1920 px (9:16)** | 세로 영상 비율 |
| 직접 입력 | 원하는 가로·세로를 픽셀로 지정 |
| 원본 크기 그대로 | 크기를 바꾸지 않고 보정과 워터마크만 적용 |

사진마다 다른 출력 크기를 고를 수 있고, 한 번에 처리하면 각자 지정한 크기로 저장됩니다.

| 맞추는 방식 (사진별) | 설명 |
| --- | --- |
| **Crop to Fill** (기본값) | 비율을 유지한 채 화면을 꽉 채우고, 넘치는 부분만 잘라냅니다. |
| Fit | 사진 전체가 보이도록 맞추고, 남는 영역은 고른 배경색으로 채웁니다. |
| Stretch | 강제로 늘립니다. 비율이 깨지므로 인물·상품 사진에는 권장하지 않습니다. |
| AI Expand | **추후 지원 예정.** 지금 고르면 안내가 뜨고 Fit 방식으로 처리됩니다. |

### 오른쪽 3. 크롭 위치
Crop to Fill 일 때만 씁니다. 왼쪽 미리보기에서 **크롭 위치 조정** 을 누르고,
빨간 프레임을 **마우스로 끌어** 구도를 잡으세요.

- 프레임 비율은 고른 출력 비율로 **고정**되어 있어 아무리 끌어도 결과가 찌그러지지 않습니다.
- 프레임 **모서리**를 끌면 확대/축소됩니다 (배율 1.00× = 사진을 가장 크게 쓰는 상태).
- 지금 잘리는 영역이 `원본 3000 × 1200 px 에서 (1050, 0) 부터 900 × 1200 px 를 잘라…` 처럼 숫자로도 표시됩니다.
- **가운데로 되돌리기** 버튼으로 언제든 초기화할 수 있습니다.

### 오른쪽 4. 톤 보정

전부 **0이 기본값이고, 0이면 원본 픽셀이 하나도 바뀌지 않습니다.**

| 슬라이더 | 범위 | 무엇이 바뀌나 |
| --- | --- | --- |
| Brightness 밝기 | -100 ~ +100 | 중간 밝기를 올리고 내립니다. 밝은 부분이 잘 타지 않습니다. |
| Exposure 노출 | -100 ~ +100 | 카메라 노출처럼 전체 광량을 조절합니다 (최대 ±1.5스톱). |
| Contrast 대비 | -100 ~ +100 | 밝은 곳과 어두운 곳의 차이 |
| Highlights 하이라이트 | -100 ~ +100 | **밝은 영역만** 조절. 하늘이 하얗게 날아갔을 때 내려 주세요. |
| Shadows 그림자 | -100 ~ +100 | **어두운 영역만** 조절. 얼굴이 어두울 때 올려 주세요. |

### 오른쪽 5. 색감 보정

| 슬라이더 | 범위 | 무엇이 바뀌나 |
| --- | --- | --- |
| Saturation 채도 | -100 ~ +100 | -100 이면 완전 흑백, +면 색이 진해집니다. |
| Temperature 색온도 | -100 ~ +100 | 음수 = 차갑게(파랑), 양수 = 따뜻하게(주황) |
| Tint | -100 ~ +100 | 음수 = Green, 양수 = Magenta |
| Sharpness 선명도 | -100 ~ +100 | 음수 = 부드럽게(블러), 양수 = 또렷하게(언샵 마스크) |

### 오른쪽 6. 워터마크 설정 (모든 사진 공통)
- 배경이 투명한 로고 PNG 를 올립니다.
- 위치 · 크기 · 투명도 · Margin X/Y 는 **모든 사진에 똑같이** 적용됩니다.
  어느 사진을 보고 있든 여기서 바꾸면 전부에 반영됩니다.
  매번 올리기 번거로우면 이 폴더의 **`watermark.png` 파일을 내 로고 파일로 바꿔치기** 해 두세요.
- **중요:** 워터마크 크기와 위치는 **최종 출력 크기(예: 1080 × 1440)** 기준으로 계산됩니다.
  그래서 원본이 가로 사진이든 세로 사진이든, 결과에서는 **항상 같은 자리에 같은 크기**로 들어갑니다.

기본값: 오른쪽 아래 / 너비 25% / 투명도 70% / Margin X 2.0% · Margin Y 1.2%
(1080 × 1440 기준으로 워터마크 폭 270px, 오른쪽 22px, 아래 17px)

### 오른쪽 7. 보정 초기화
**지금 고른 사진의** 톤·색감 값 9개를 전부 0으로 되돌립니다. 다른 사진은 그대로입니다.

### 오른쪽 8. 전체 이미지에 적용
**현재 사진의 톤 · 색감 · Sharpness 를 나머지 모든 사진에 복사**합니다. 버튼을 직접 눌렀을 때만 동작합니다.

- Crop Position 은 사진마다 구도가 다르므로 복사하지 않습니다.
- 워터마크는 원래 공통 설정이라 이 버튼과 무관합니다.

### 아래. 전체 이미지 처리 → 다운로드
- **전체 이미지 처리** 버튼을 누르면 사진마다 저장된 개별 설정으로 각각 처리됩니다.
- 한 장이면 그 파일 하나, 여러 장이면 **전체 ZIP 다운로드** 버튼이 나옵니다.
- 이름은 `여행사진.jpg` → `여행사진_edited.jpg` 로 붙습니다.

## 5. 처리 순서

프로그램은 항상 아래 순서로 한 장씩 처리합니다. 순서는 바뀌지 않습니다.

```
1. EXIF orientation 보정   스마트폰 사진의 회전 정보를 실제 픽셀에 반영
        ↓
2. 크롭 / 리사이즈         드래그로 잡은 영역(출력 비율과 같은 모양)을 잘라 출력 크기로 변환
        ↓
3. 톤 보정                 노출 → 밝기 → 대비 → 하이라이트 → 그림자
        ↓
4. 색감 보정               채도 → 색온도 → Tint → Sharpness
        ↓
5. 워터마크 합성           ← 여기서 처음 등장. 위 보정이 워터마크에 닿지 않음
        ↓
6. 파일 저장               JPG quality 95 · 색상 프로파일 유지
```

보정은 8비트가 아니라 **32비트 실수로 계산한 뒤 마지막에 한 번만 8비트로 되돌립니다.**
하이라이트·그림자 마스크도 부드러운 곡선(smoothstep)이라 하늘 같은 그라디언트에 계단(밴딩)이 생기지 않습니다.

## 6. 프로젝트 구조

```
watermark-tool/
├── app.py                    프로그램 본체
├── requirements.txt          필요한 부품 목록
├── config.json               내가 정한 설정이 저장되는 곳 (자동 생성/수정)
├── watermark.png             기본 워터마크 이미지 (내 로고로 바꿔 쓰세요)
├── README.md                 이 설명서
├── mac/
│   └── install-mac.command   맥 설치 프로그램 (처음 한 번만 실행)
│
│  ↓ 설치하면 아래 두 개가 생깁니다 (맥 전용)
├── 워터마크 툴.app           더블클릭 → 실행
└── 워터마크 툴 종료.app      더블클릭 → 종료
```

`.app` 두 개는 설치할 때 **이 컴퓨터의 폴더 위치를 기억한 채로 만들어집니다.**
그래서 저장소에는 들어 있지 않고, 각자 컴퓨터에서 설치를 돌려야 생깁니다.
`.app` 자체는 독이나 다른 폴더로 옮겨도 잘 동작하지만, **프로그램 폴더를 옮기면**
설치를 한 번 더 실행해 주세요.

### config.json 에 저장되는 값

설정을 바꾸면 **자동으로** 저장됩니다. 다음에 켤 때 **워터마크 · 출력 크기 · 맞추는 방식 · 저장 옵션**은
그대로 복원되고, **톤 · 색감 · 크롭 위치**는 사진마다 손대지 않은 상태(0 · 가운데)에서 시작합니다.
(한 사진에 준 보정이 다음에 올리는 다른 사진에 따라붙지 않도록 하기 위해서입니다.)
직접 손댈 필요는 없습니다. 값이 잘못되어 있으면 그 항목만 기본값으로 되돌아가고 프로그램은 계속 돌아갑니다.

| 항목 | 뜻 | 기본값 |
| --- | --- | --- |
| `canvas_mode` | `preset_3_4` · `preset_9_16` · `custom` · `original` | `preset_3_4` |
| `canvas_w` / `canvas_h` | 직접 입력했을 때의 출력 크기 | `1080` / `1440` |
| `fit_mode` | `crop` · `fit` · `stretch` · `expand` | `crop` |
| `crop_x` / `crop_y` | 크롭 위치 0~100 (드래그하면 자동으로 채워짐) | `50` / `50` |
| `crop_zoom` | 크롭 배율 (1.0 = 사진을 가장 크게 씀) | `1.0` |
| `bg_color` | Fit 방식에서 남는 영역 색 | `#FFFFFF` |
| `brightness` `exposure` `contrast` `highlights` `shadows` | 톤 보정 -100~+100 | 전부 `0` |
| `saturation` `temperature` `tint` `sharpness` | 색감 보정 -100~+100 | 전부 `0` |
| `size_mode` | 워터마크 크기 기준 `percent` · `pixel` | `percent` |
| `size_percent` / `size_px` | 워터마크 너비 (출력 너비의 % / px) | `25.0` / `300` |
| `opacity` | 워터마크 투명도 0~100 | `70` |
| `position` | `top_left` `top_right` `bottom_left` `bottom_right` `center` `custom` | `bottom_right` |
| `margin_mode` | 여백 기준 `percent` · `pixel` | `percent` |
| `margin_x_percent` / `margin_y_percent` | 좌우 / 위아래 여백 % | `2.0` / `1.2` |
| `margin_x_px` / `margin_y_px` | 좌우 / 위아래 여백 px | `24` / `24` |
| `custom_unit` | 사용자 지정 X/Y 단위 | `percent` |
| `custom_x_percent` / `custom_y_percent` | 사용자 지정 X / Y (%) | `78.0` / `88.0` |
| `custom_x_px` / `custom_y_px` | 사용자 지정 X / Y (px) | `0` / `0` |
| `output_format` | `jpeg` · `keep`(원본 형식 유지) | `jpeg` |
| `name_suffix` | 파일 이름 뒤에 붙는 말 | `_edited` |

## 7. 화질에 대해 지키는 규칙

| 규칙 | 어떻게 지키는지 |
| --- | --- |
| 정확한 출력 크기 | 결과는 언제나 정확히 지정한 픽셀 크기입니다. 화면에도 결과 크기가 표시되고, 전부 맞을 때만 "정확히 1080 × 1440 px 입니다" 문구가 나옵니다. |
| 비율 안 깨짐 | 잘라내는 영역이 출력 비율과 정확히 같은 모양이라, 가로·세로가 똑같은 배율로 줄어듭니다. 비율이 깨지는 건 직접 고른 Stretch 뿐입니다. |
| 미리보기 왜곡 없음 | 미리보기 이미지는 항상 실제 비율대로 표시됩니다 (표시 비율 = 파일 비율). |
| 사진 회전 | EXIF 회전 정보를 실제 픽셀에 반영한 뒤 태그를 정리해, 어디서 열어도 똑바로 보입니다. |
| 워터마크 보호 | 워터마크는 모든 보정이 끝난 뒤에 얹힙니다. 사진마다 톤·색감을 다르게 줘도 워터마크는 색·위치·크기가 완전히 동일합니다. |
| 부드러운 보정 | 32비트 실수 연산 + 부드러운 마스크로 계산해 밴딩(계단 현상)이 생기지 않습니다. |
| 리샘플링 품질 | 크기 변환은 LANCZOS(고품질) 방식입니다. |
| Sharpness | 양수는 언샵 마스크, 음수는 가우시안 블러입니다. 0이면 필터를 아예 거치지 않습니다. |
| JPG 품질 | `quality=95` 로 저장합니다. |
| 색상 프로파일 | 원본에 ICC 프로파일이 있으면 결과에도 그대로 붙입니다. |
| PNG 투명도 | "원본 크기 그대로 + 원본 형식 유지"로 저장하면 투명도가 유지됩니다. JPG 로 저장할 때는 투명한 부분이 배경색으로 채워집니다. |

## 8. 잘 안 될 때

### 맥에서 실행 앱이 말썽일 때

| 증상 | 해결 |
| --- | --- |
| `install-mac.command` 더블클릭이 안 됨 / `악성 코드가 없음을 확인할 수 없습니다` | 정상입니다. `완료` 를 누르고, 터미널에서 `bash ` 를 친 뒤 파일을 끌어다 놓아 실행하세요. |
| 그래도 더블클릭으로 하고 싶다 | `시스템 설정 → 개인정보 보호 및 보안` 맨 아래의 **`그래도 열기`** 를 누르세요. |
| `워터마크 툴.app` 을 눌러도 아무 반응이 없음 | 처음 열 때 5~15초 걸립니다. 그래도 안 되면 터미널에 `open "워터마크 툴.app"` 을 쳐 보세요. 이유가 표시됩니다. 대부분 `mac/install-mac.command` 를 다시 실행하면 해결됩니다. |
| 터미널에서는 되는데 더블클릭만 안 됨 | 예전 버전으로 만든 앱입니다. 최신 코드를 받아 `mac/install-mac.command` 를 다시 실행하세요. 지금은 애플 기본 도구(osacompile)로 앱을 만들어 이 문제가 생기지 않습니다. |
| "프로그램 폴더를 찾을 수 없습니다" | 프로그램 폴더를 옮기거나 이름을 바꾼 경우입니다. `mac/install-mac.command` 를 다시 실행하세요. |
| "실행에 필요한 부품이 설치되어 있지 않습니다" | `mac/install-mac.command` 를 다시 실행하세요. |
| 브라우저 탭을 닫았는데 프로그램이 계속 켜져 있음 | 정상입니다. 완전히 끄려면 **`워터마크 툴 종료.app`** 을 누르세요. |
| 종료 앱을 눌렀는데 "실행 중인 워터마크 툴이 없습니다" | 이미 꺼져 있다는 뜻이라 괜찮습니다. |

### 공통

| 증상 | 해결 |
| --- | --- |
| `pip` 또는 `python` 을 찾을 수 없다고 나옴 | 파이썬 설치 때 **Add python.exe to PATH** 를 안 켠 경우입니다. 파이썬을 지우고 그 항목을 켠 채 다시 설치하세요. |
| `streamlit` 또는 `numpy` 를 찾을 수 없다고 나옴 | 3단계 설치 명령(`pip install -r requirements.txt`)을 다시 실행하세요. |
| 브라우저가 안 열림 | 주소창에 `http://localhost:8501` 을 직접 입력하세요. |
| 사진의 중요한 부분이 잘림 | **크롭 위치 조정** 에서 프레임을 끌어 옮기세요. 전체를 다 보여주고 싶다면 **Fit** 방식을 고르세요. |
| 크롭 화면에 프레임이 안 뜸 | 드래그 편집기(`streamlit-cropper`)가 설치되지 않은 경우입니다. `pip install -r requirements.txt` 를 다시 실행하세요. 설치 전에는 X/Y 슬라이더로 대신 조정할 수 있습니다. |
| 워터마크가 안 보임 | 투명도가 0에 가깝거나 크기가 너무 작지 않은지 확인하세요. 흰 배경에 흰 로고면 원래 잘 안 보입니다. |
| 색이 이상해짐 | **보정 초기화** 버튼을 누르면 그 사진의 톤·색감이 전부 0으로 돌아갑니다. |
| 다른 사진 설정이 안 따라옴 | 정상입니다. 사진마다 따로 저장됩니다. 같게 맞추려면 **전체 이미지에 적용** 버튼을 누르세요. |
| AI Expand 를 골랐는데 배경만 채워짐 | 아직 지원 전이라 Fit 방식으로 처리됩니다. |
| 설정이 저장되지 않음 | 폴더가 읽기 전용일 수 있습니다. 바탕화면 등 쓰기 가능한 곳으로 폴더를 옮기세요. |
| 슬라이더 반응이 느림 | 고화소 사진일수록 첫 미리보기가 느립니다. 한 번 계산된 뒤에는 빨라집니다. |

## 9. 참고

- 처리는 전부 로컬(내 컴퓨터)에서 이뤄지며, 원본 파일은 수정되지 않습니다.
- 지원 형식: JPG / JPEG / PNG / WEBP · 파일당 최대 200MB
- 사용 라이브러리: [Streamlit](https://streamlit.io) (화면), [Pillow](https://python-pillow.org) (이미지), [NumPy](https://numpy.org) (보정 연산), [streamlit-cropper](https://pypi.org/project/streamlit-cropper/) (드래그 크롭)
